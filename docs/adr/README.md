# Architecture decision records

Short records of decisions that shape this repository. Add a new numbered
file, `NNNN-<slug>.md`, when a decision changes how the distro is built or
run. When an accepted decision changes in part, amend the record with a
dated `## Amendment` section at the end and name each amendment on its
status line; when it is replaced whole, supersede it with a new record.
